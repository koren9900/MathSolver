# MathSolver

This project is a small Java based interpreter that can parse and evaluate simple mathematical expressions. The solver supports arithmetic with numbers and vectors as well as several built‑in functions.

## Features

- Parsing of numeric expressions and vector expressions using a recursive descent parser.
- Basic arithmetic operators: `+`, `-`, `*`, `/`, and exponent `^`.
- Factorial operator `!` and unary negation.
- Vector math with element wise addition and subtraction and scalar multiplication/division.
- Built‑in functions such as `max`, `min`, `abs`, `ceil`, `floor`, `round`, `log`, `sqrt`, and `root`.
